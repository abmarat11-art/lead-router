# lead-router — контур распределения лидов

Забирает строки из гуглтаблицы лидгена, ведёт очередь и назначения, отдаёт события
в Аргус (CRM) вебхуками.

```
Google Sheets → импортёр (дедуп, карантин) → очередь → предложение сотруднику
   → акцепт / отказ / протухание → назначение → вебхук в Аргус
```

Б24 в коде не фигурирует: источник — таблица, приёмник — Аргус. Когда таблицу начнёт
наполнять не расширение Б24, а сама CRM, менять в контуре нечего — формат колонок тот же.

## Запуск

```bash
npm install
cp .env.example .env      # заполнить SHEETS_* и ARGUS_WEBHOOK_URL
npm run migrate
node src/db/seed.js       # опционально: демо-команда и 4 лида
npm start                 # http://localhost:3000
npm test
```

Без `SHEETS_SPREADSHEET_ID` импорт из шита просто не запускается — контур работает
на строках, залитых через `POST /api/import/rows`. Без `ARGUS_WEBHOOK_URL` вебхуки
не копятся в очереди, вся история остаётся в `events`.

## Как устроено распределение

- **Состояния лида:** `new → offered → assigned`, плюс `queued` (вернулся в очередь),
  `escalated` (некому отдать / затолкали), `quarantine` (строка не прошла валидацию).
- **Предложение с таймером.** Сотрудник получает лид на `OFFER_TTL_MINUTES` (по умолчанию 15).
  Не ответил — лид уходит следующему, сотруднику пишется «просрочил».
- **Отказ не по кругу.** Тому, кто отказался или просрочил, этот лид больше не предлагается.
  После 3 отказов подряд лид не гуляет дальше, а попадает в «Эскалацию» — на стол руководителю.
- **Фильтры перед выдачей:** активен, состоит в нужной команде, язык клиента входит в его языки,
  не выбран дневной лимит.
- **Стратегии команды:** `round_robin` (по кругу, курсор хранится в команде) и
  `balance` (кому меньше сейчас в работе).
- **Ручное назначение** из интерфейса отменяет висящее предложение и назначает напрямую.

## Импорт из таблицы

- Ключ строки — `Лист:номер_строки`, содержимое хешируется. Правку задним числом видно:
  данные лида обновляются, назначение не сбрасывается, в `events` пишется `source_row_changed`.
- Колонки определяются по синонимам заголовков (`src/core/normalize.js`), незнакомые колонки
  сохраняются целиком в `raw` — ничего не теряется.
- Телефон нормализуется (`901234567` → `+998901234567`), язык и итог приводятся к
  `ru/uz/en` и `lead/meeting`.
- Строка без контактов или без итога уходит в **карантин**, а не теряется молча.
  Дубль по телефону/почте/компании — туда же, с пометкой.

## Вебхуки в Аргус

Транзакционный outbox: событие сначала ложится в таблицу, воркер шлёт его раз в 10 секунд
с бэкоффом `0 → 30с → 2м → 10м → 1ч`, после чего помечает `failed`. Падение CRM не ломает
распределение.

События: `lead.assigned`, `lead.declined`, `lead.expired`, `lead.escalated`.

```json
{
  "id": "uuid", "event": "lead.assigned", "occurred_at": "2026-09-07T10:00:00.000Z",
  "lead": { "id": 1, "source_key": "Лист1:2", "company": "ООО Ромашка",
            "phone": "+998901234567", "lang": "ru", "outcome_type": "lead",
            "lead_gen": "Лидген-1", "raw": {} },
  "employee": { "id": 1, "name": "Аня", "tg_user_id": null, "team_id": 1 }
}
```

Тело подписывается HMAC-SHA256 (`ARGUS_WEBHOOK_SECRET`) в заголовке `x-lead-router-signature`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/leads?status=` | список лидов с текущим предложением |
| GET | `/api/teams` | команды и состав |
| GET | `/api/stats` | счётчики по статусам, по сотрудникам, по outbox |
| GET | `/api/events` `/api/outbox` | журнал и очередь вебхуков |
| POST | `/api/import` | импорт из шита сейчас |
| POST | `/api/import/rows` | залить строки вручную `{headers, rows, team_id}` |
| POST | `/api/dispatch` | разобрать пул |
| POST | `/api/leads/:id/offer` `/assign` `/release` `/escalate` `/team` | действия по лиду |
| POST | `/api/offers/:id/accept` `/decline` | ответ сотрудника |
| POST/PATCH | `/api/teams` `/api/employees` `/api/employees/:id` | справочники |

## Интерфейс

`/` — вкладки: Пул, Предложены, В работе, Карантин, Эскалация, Команды, Мониторинг.
Кнопки «Импорт сейчас» и «Распределить пул», ручное назначение селектом, возврат из карантина.
