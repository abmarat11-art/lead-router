## Текущее состояние (14.09.2026)

- Цепочка таблица → Б24 → очередь → таблица → уведомления проверена живьём, тесты 156/156.
- `ARGUS_AUTOSEND=0`: компании в Аргус уезжают только кнопкой. Включить — `ARGUS_AUTOSEND=1`
  в `.env` + перезапуск. Решение принимает Марат.
- Аргус — боевой адрес. Метода удаления компаний в API нет: живые прогоны создают реальные карточки.
- До запуска в таблице тестовые строки. Перед боевым стартом: `node scripts/launch-reset.js <первая боевая строка>`
  и перезапуск — стирает накопленное, команды и привязки к боту остаются.
- Без телеграма: Владимир Пак, Тагир Солиев — им нажать «Старт» у бота и прислать ID из Аргуса.

## Повседневные команды

```bash
cd ~/projects/dima/lead-router
npm test                                        # тесты
node scripts/check-header.js                    # сверить шапку таблицы с конфигом
node scripts/add-user.js <login> "<Имя>"        # завести/сбросить пароль пользователя панели
node scripts/launch-reset.js <строка>           # обнуление перед боевым стартом
launchctl kickstart -k gui/$(id -u)/net.at-km.lead-router   # перезапуск службы
tail -f ~/ai-server/logs/lead-router.log        # лог
```
