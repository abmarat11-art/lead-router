# Инструкции по контуру лидов

Контур лидов — это связка между отделом лидогенерации, таблицей, Битриксом и Аргусом.
Лидген отправляет компанию → контур сам выбирает команду по очереди → заводит компанию
в Аргусе на ответственного этой команды → шлёт уведомление в телеграм → команда отмечает
результат → лидген видит статус в своей же таблице.

Никто ничего не распределяет руками. Задача человека — аккуратно заполнить свою часть
и вовремя отметить результат.

## Кому что читать

| Роль | Что делает | Инструкция |
|---|---|---|
| **Лидоген** | отправляет компании из Битрикса, следит за статусами в таблице | [01-lidgen.md](01-lidgen.md) |
| **Менеджер** | получает уведомление, берёт компанию в работу, отмечает результат | [02-manager.md](02-manager.md) |
| **Руководитель** | следит за очередью, составом команд, отказами и фидбэком | [03-supervisor.md](03-supervisor.md) |

Общая картина процесса и словарь статусов — [00-process.md](00-process.md).
Начинать лучше с него: он короткий, и после него две другие инструкции читаются за пять минут.

## Куда заходить

- Интерфейс контура: **https://lidgen.at-km.net** — вход по логину и паролю (выдаёт руководитель).
- Бот уведомлений: **@lidgen_CP_bot** — один раз нажать «Старт» и прислать свой ID из Аргуса.
- Таблица лидогенерации — ссылка у руководителя отдела.

## Про скриншоты

Все скриншоты сняты на демо-стенде с вымышленными компаниями и людьми
(«Delta Trade LLC», «Команда Регионы» и т. п.). Реальные названия и контакты
в инструкции не публикуются. Интерфейс — тот же самый.
